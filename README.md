Sales Analytics Dashboard

Project Overview

An interactive sales analytics dashboard developed using Python, Pandas, and Streamlit. It helps businesses monitor sales performance and analyse important business metrics.

Features

- Interactive regional and customer segment filters
- Revenue, profit, cost and profit margin KPIs
- Revenue analysis by region
- Profit analysis by region
- Customer segment analysis
- Monthly sales trend analysis
- Black-and-gold dashboard design
- Downloadable, formatted Excel sales reports

Technologies Used

- Python
- Pandas
- Streamlit
- OpenPyXL

How to Run the Project

1. Install Python.

2. Install the required libraries:
   
   "pip install streamlit pandas openpyxl"

3. Place the Excel workbook named "Sales Inventory Analytics.xlsx" in the project folder, with an "Orders" sheet.

4. Run:
   
   "python -m streamlit run interactive_dashboard.py"
